# AI INCOME OS

A mobile-first black-and-silver income and expense dashboard.

## Features
- Net balance, total income, total expenses, and savings-rate calculation
- Add income and expense entries with category and date
- Recent transaction list with delete controls
- Spending and savings observations based on your entries
- Export transactions to a JSON backup
- Responsive phone and desktop layout; no build tools or paid service required

## Run
Open `index.html` in a browser, or enable GitHub Pages for this repository.

## Data and privacy
This prototype stores entries in browser local storage on the device/browser in use. There is no cloud database, login, cross-device sync, or live AI connection in this version. Clearing browser site data may erase records; export a backup regularly. Never store passwords, UPI PINs, or bank/card secrets here.
